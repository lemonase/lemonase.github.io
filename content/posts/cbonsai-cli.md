Hello, I am back again sharing a mostly useless, but very pretty and awesome
CLI program called `cbonsai`

Repo is here:
https://gitlab.com/jallbrit/cbonsai

It can be installed (on Mac) using

```shell
brew install cbonsai
```

This is the result:

![bonsai_tree](/images/posts/cbonsai-cli/bonsai_tree.png)

You can also use it in screensaver mode `cbonsai -S` where you can see the
trees being continuously generated live.

![bonsai_tree_gif](/images/posts/cbonsai-cli/bonsai_tree.gif)

Really cool and oddly satisfying.

It is well known that programmers enjoy trees, but this takes it to a whole
other level.
